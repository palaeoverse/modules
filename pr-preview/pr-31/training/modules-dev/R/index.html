This module introduces you to R, RStudio, and R project management. R is a free, open-source programming language designed for data analysis and visualisation. RStudio is an integrated development environment (IDE) that makes working with R far more approachable. Together, they form one of the most widely used toolkits in palaeontology, ecology, and evolutionary biology.

No prior coding experience is required for this module, and by the end, you will be comfortable navigating RStudio, writing and running simple R code, and organising your work in a project that you (or a collaborator) can return to months later.

Learning objectives

By the end of this module, you will be able to:

  • Explain what R and RStudio are and how they relate
  • Identify the main RStudio panels and what they do
  • Distinguish between the RStudio console and a script
  • Assign values to objects and manipulate them
  • Recognise common data types and structures
  • Install and load packages
  • Import a dataset, inspect it, and summarise it
  • Make a simple plot in base R
  • Interpret common errors and find help independently
  • Create an RStudio Project to organise your work
  • Code in R and RStudio with confidence

Prerequisites

Knowledge

This module assumes no prior experience with R or programming. However, you should be comfortable with basic computer skills, such as downloading and installing software and managing files and folders.

Installation

For this module, you will need to install R and RStudio. Install R first, as RStudio relies on it.

  1. Install R. Download the latest version for your operating system from the Comprehensive R Archive Network (CRAN) and follow the installation instructions.
  2. Install RStudio Desktop. Download the free version from the Posit website and install it as you would any other application.
TipTrouble installing?

If you cannot install software on your machine (e.g. a managed institutional laptop), you can run RStudio in your browser for free using Posit Cloud. Alternatively, speak to your IT support team about installing R and RStudio.

Module structure

This module is designed to get you up and running with R and RStudio as quickly as possible and includes the following:

  • Introduction to R and RStudio: Get to know the RStudio interface and understand how R and RStudio work together.
  • R Basics: Learn the fundamentals of the R language, including objects, data types, functions, packages, and importing data.
  • Project Management with RStudio: Organise your files, data, and code with RStudio Projects, and adopt habits that make your analyses reproducible.
